# 今天也没守住 · 微信小游戏版

这是与 `guardian-gate-web` 并列的独立微信小游戏工程。网页版没有被修改；两端仅共享经过验证的玩法规则和原创资产来源。

项目使用微信开发者工具要求的 `compileType: game`，构建产物位于独立的 `dist/` 游戏根目录。

## 已实现的小游戏能力

- 七关卡战役：Stage 01“关外练兵场”、Stage 02“东海礁港”、Stage 03“镇海龙门”、Stage 04“归墟潮眼”、Stage 05“扶桑天阙”、Stage 06“太初蜃庭”和终章 Stage 07“山河残卷”各有独立路线、塔位与五波敌潮
- 通关第七关后解锁 Stage 08“无尽潮渊”：Seed 从 A/B/C 三路中固定一路，前 20 分钟持续生成威胁包，随后挑战分层重生的“深渊龙王”，25 分钟自动结算
- 无尽成绩按 A/B/C 路线分别保存：未进入龙王阶段时比较生存时长，进入后比较龙王累计实际伤害，不与其他路线混榜
- 通关后逐关解锁下一关，结算页可直接进入新关卡，首页可切换所有已解锁关卡
- 第二关采用暴风前夜的玄武岩礁港背景，共 130 名敌人；敌人完全进入画面后才可被攻击，后三波保持成群推进
- 第三关采用风暴龙门背景，共 141 名敌人；疾潮速度逐波提升，第三波起加入礁甲卫，终波由“玄甲龙鳌”首领先压线、护卫随后追赶
- 第四关越过龙门进入黑玉归墟祭海台，共 165 名敌人；“残血狂潮”会让噬潮鳞卫与首领“噬潮魔蛟”在低血量时显著加速
- 第五关登临扶桑天阙迎战 184 名蚀日潮军；“曜阵祭司”和首领“蚀日鲲皇”会展开护阵光环，为范围内友军提升护甲，需要优先击破阵眼
- 第六关深入黑珍珠母贝构成的太初蜃庭，共 195 名敌人；“蜃壳镜卫”和首领“万相蜃母”在高血阶段以相壳限制单支箭伤害，鼓励用攻速、箭数和穿透持续破壳
- 第七关展开宣纸山河与反相墨境交叠的残卷，共 216 名敌人；“虚相行者”和首领“双相天蠹”会错峰进入虚相并大幅减伤，需要抓住实体窗口持续集火
- 固定战役以两座箭塔开局；每波前有 6 秒备战与敌情预览，完成第 2 / 4 波分别解锁第三、第四座塔，建塔不占用每波两次技能兑换次数
- 备战期可在 32px 网格上自由建塔或拖动已建塔；落点需同时避开怪物路线、其他塔和关印，绿/红落点预览会在确认前给出反馈
- 击杀敌人获得局内战功；战功面板旁常驻 3 个技能快捷位，展示属性变化、价格与差额，可兑换时亮起并打开原确认层；Stage 08 保持三塔与免费三选一规则
- 已部署箭塔自动索敌并分担首要目标：点塔选择，拖动战场调整当前箭塔的集火方向；锥内发动完整齐射与集火加成，锥外降级为单箭自动补位
- 最多四座差异化海防塔采用独立透明塔基与可旋转弩机；部署后保留编号、塔头与分段选中光环
- 七关战役与无尽挑战共享真实终点关印：战场镜头会把完整路线等比收进 HUD 安全区，敌人触及画面中的关印即按规则扣耐久；底部信息分置左右两侧，中央保留道路、关印与塔位通道
- 塔弓与搭箭会自动跟随当前首要目标，发射瞬间保留准确朝向与后坐反馈
- 多类透明战斗怪物、方向动画、分层血条，以及普通/穿透/暴击箭矢和命中特效
- 暂停、继续、1/2 倍速和音效开关（不包含循环背景音乐）
- 固定战役的境界随击杀自动提升，法门改为消耗战功的三选一商店；Stage 08 无尽挑战继续沿用免费升级三选一与重抽规则
- 战役关与无尽挑战每局最多各有一次重燃机会
- 战役胜利结算、进入下一关和重新挑战；无尽关使用独立战报，不会显示“胜利”或“全波清剿”
- 使用微信本地存储分别保存八个关卡槽位的战斗快照、七关战役解锁进度、最后选中的关卡与无尽三路纪录；旧版七关全通进度会自动解锁无尽挑战
- `wx.onHide` / `wx.onShow` 生命周期暂停与续局
- `wx.createInnerAudioContext` 音频适配
- 为 iOS/Android 真机生成 M4A 音频，并提供 JPG 战场背景
- 横屏 Canvas 2D 渲染、高分屏与动态宽高比适配，宽屏背景全屏延展并避让系统安全区和右上胶囊

## 本地运行

```bash
npm install
npm run qa
npm run dev
```

`npm run dev` 会先构建 `dist/`，再通过微信开发者工具 CLI 打开本工程。

## 目录

```text
guardian-gate-minigame/
├── src/
│   ├── core/                 # 从 Web 版复用并独立维护的战斗内核与内容
│   ├── platform/             # 微信存档、音频、编码和运行时适配
│   ├── render/               # Canvas 2D 战场与界面
│   ├── GuardianGateGame.ts   # 小游戏状态与输入总控
│   └── game.ts               # 微信小游戏入口
├── assets/stage-01/          # 原创 Stage 01 运行时资产
├── assets/stage-02/          # 原创 Stage 02 夜潮礁港背景
├── assets/stage-03/          # 原创 Stage 03 风暴龙门背景与玄甲龙鳌首领
├── assets/stage-04/          # 原创 Stage 04 归墟潮眼背景与噬潮魔蛟首领
├── assets/stage-05/          # 原创 Stage 05 扶桑天阙背景与蚀日鲲皇首领
├── assets/stage-06/          # 原创 Stage 06 太初蜃庭背景与万相蜃母首领
├── assets/stage-07/          # 原创 Stage 07 山河残卷背景与双相天蠹首领
├── assets/stage-08/          # 原创 Stage 08 无尽潮渊背景与深渊龙王首领
├── dist/                     # 微信开发者工具实际加载目录
├── game.json
└── project.config.json
```

Stage 01 共享战斗资源保留在主包；Stage 02–08 的背景和独立首领位于各自普通分包，选关或进入战斗时才增量加载，离开后释放关卡专属图片。

## AppID

工程已配置微信开发者工具生成的“小游戏测试号”，可用于本地模拟器开发。真机预览、上传和发布前，把 `project.config.json` 中的 `appid` 换成正式小游戏 AppID。
