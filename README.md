# 今天也没守住 · 微信小游戏版

这是与 `guardian-gate-web` 并列的独立微信小游戏工程。网页版没有被修改；两端仅共享经过验证的玩法规则和原创资产来源。

项目使用微信开发者工具要求的 `compileType: minigame`，构建产物位于独立的 `dist/` 游戏根目录。

## 已实现的小游戏能力

- 六关卡战役：Stage 01“关外练兵场”、Stage 02“东海礁港”、Stage 03“镇海龙门”、Stage 04“归墟潮眼”、Stage 05“扶桑天阙”和终章 Stage 06“太初蜃庭”各有独立路线、塔位与五波敌潮
- 通关后逐关解锁下一关，结算页可直接进入新关卡，首页可切换所有已解锁关卡
- 第二关采用暴风前夜的玄武岩礁港背景，共 70 名敌人；敌人完全进入画面后才可被攻击，后三波保持成群推进
- 第三关采用风暴龙门背景，共 84 名敌人；疾潮速度逐波提升，第三波起加入礁甲卫，终波由“玄甲龙鳌”首领先压线、护卫随后追赶
- 第四关越过龙门进入黑玉归墟祭海台，共 93 名敌人；“残血狂潮”会让噬潮鳞卫与首领“噬潮魔蛟”在低血量时显著加速
- 第五关登临扶桑天阙迎战蚀日潮军；“曜阵祭司”和首领“蚀日鲲皇”会展开护阵光环，为范围内友军提升护甲，需要优先击破阵眼
- 第六关深入黑珍珠母贝构成的太初蜃庭，共 103 名敌人；“蜃壳镜卫”和首领“万相蜃母”在高血阶段以相壳限制单支箭伤害，鼓励用攻速、箭数和穿透持续破壳
- 三座箭塔默认自动索敌并分担首要目标：点塔选择，拖动战场只调整当前箭塔的优先方向，锥外目标仍会自动补位
- 三座差异化海防塔采用独立透明塔基与可旋转弩机，保留清晰的编号和分段选中光环
- 六关共享贴地终点关印与连续底部信息层，并按关城、礁港、龙门、归墟、扶桑、蜃庭主题切换配色和纹样；终点不再遮挡场景建筑或底部 HUD
- 塔弓与搭箭会自动跟随当前首要目标，发射瞬间保留准确朝向与后坐反馈
- 多类透明战斗怪物、方向动画、分层血条，以及普通/穿透/暴击箭矢和命中特效
- 暂停、继续、1/2 倍速和音效开关（不包含循环背景音乐）
- 境界升级后三选一卡牌与免费重抽
- 失败后最多两次重燃复活
- 胜利结算、进入下一关和重新挑战
- 使用微信本地存储分别保存六关战斗快照、解锁进度和最后选中的关卡；旧版五关全通进度会自动解锁第六关
- `wx.onHide` / `wx.onShow` 生命周期暂停与续局
- `wx.createInnerAudioContext` 音频适配
- 为 iOS/Android 真机生成 M4A 音频，并提供 JPG 战场背景
- 横屏 Canvas 2D 渲染和高分屏适配

## 本地运行

```bash
npm install
npm run qa
npm run dev
```

`npm run dev` 会先构建 `dist/`，再通过微信开发者工具 CLI 打开本工程。

## 目录

```text
guardian-gate-minigame/
├── src/
│   ├── core/                 # 从 Web 版复用并独立维护的战斗内核与内容
│   ├── platform/             # 微信存档、音频、编码和运行时适配
│   ├── render/               # Canvas 2D 战场与界面
│   ├── GuardianGateGame.ts   # 小游戏状态与输入总控
│   └── game.ts               # 微信小游戏入口
├── assets/stage-01/          # 原创 Stage 01 运行时资产
├── assets/stage-02/          # 原创 Stage 02 夜潮礁港背景
├── assets/stage-03/          # 原创 Stage 03 风暴龙门背景与玄甲龙鳌首领
├── assets/stage-04/          # 原创 Stage 04 归墟潮眼背景与噬潮魔蛟首领
├── assets/stage-05/          # 原创 Stage 05 扶桑天阙背景与蚀日鲲皇首领
├── assets/stage-06/          # 原创 Stage 06 太初蜃庭背景与万相蜃母首领
├── dist/                     # 微信开发者工具实际加载目录
├── game.json
└── project.config.json
```

## AppID

工程已配置微信开发者工具生成的“小游戏测试号”，可用于本地模拟器开发。真机预览、上传和发布前，把 `project.config.json` 中的 `appid` 换成正式小游戏 AppID。
